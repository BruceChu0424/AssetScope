## 核心特性

**正确的账本**
- 复式记账 + 借贷守恒校验；转账不算消费、信用卡还款不重复记账、贷款本息拆分、浮盈卖出不重复计收益——229 个测试锁定这些硬规则。
- 金额全链路 `BigInt`（分）+ `Rational` 有理数，禁止 double；halfEven 舍入经有理数整体舍入。

**全资产负债视图**
- 现金/银行/支付宝/微信/券商/持仓（股票·基金·债券·加密）/房产/车辆/公积金/应收款/保险现金价值……总资产、总负债、净资产一屏可见；估值缺失不计为 0，过期估值显式提示。

**🌍 3D 资产地球**
- 点阵线框地球（Natural Earth 公有领域数据，92KB 全离线），固定资产呼吸标记、拖拽旋转/惯性/自转、点击飞行动画 + 详情弹层；账户支持城市快选定位。

**🧠 智慧分析（v0.2 新增）**
- 财务体检：储蓄率、应急月数、资产负债率、固定收支覆盖比。
- 消费配速：按当前速度外推月末总额与剩余日均可花。
- 异常检测：中位数 + MAD 稳健 z 分数，单月大额不污染基线。
- 周期识别：间隔中位数 ± 容差识别房租/订阅/工资，一键固化计划。
- 净资产里程碑：Theil–Sen 稳健回归预测下一个整数关口（抗离群月）。
- 商户→分类规则引擎：关键词规则 + 历史频率学习 + 模糊匹配，导入时逐行智慧分类。
- 投资组合 XIRR（组合边界内买卖分红视为内部事件）+ 持仓浮盈明细。
- 雪崩 vs 雪球还款策略逐月模拟对比。

**规划与预测**
- 月度总额与分类预算、月末/闰年感知的周期计划、目标预留与每月需存金额。
- 现金预测：按未来 N 天（30–180 可设）逐日推演 C(t) − R(t) − B(t)，识别"月底有钱但月中缺钱"；可支配上限 = max(0, min_t[·])，准备金在支出日自动释放（不双扣）。

**债务管理**
- 等额本息/等额本金/先息后本/固定分期/免息；还款计划、提前还款模拟（利息节省与手续费）、名义费率 vs IRR 有效年化、策略对比。

**月报与年度报告**
- 期末净资产 = 期初 + 收支 + 投资（已实现+分红+Δ未实现）+ 汇兑 + 其他估值 + 修正 + **待核对差额**（非 0 即数据缺口，显式暴露）。
- 年度视图（v0.3）：总收支与储蓄率、储蓄月数、月度收支柱状、分类年度排行、最大单笔消费、全年还贷本金/利息、已实现投资损益与分红（v0.5）。
- 投资组合 XIRR（资金加权）+ TWR（时间加权，月末估值点法，缺价时点作废不硬算）。

**📈 投资分析深化（v0.5 新增）**
- **风险指标**：年化波动率、最大回撤（含峰谷日期）、Sharpe、Sortino、最佳/最差月、月胜率——基于 TWR 月度子期间收益（外部现金流已剔除），无风险利率可调，样本不足显式标注。
- **资产配置与再平衡**：九类配置桶（股票/基金/债券/现金及等价物/固收理财/另类/固定资产/长期权益/其他），目标配置 + **5/25 带宽再平衡建议**（Vanguard 阈值法，交易回带边而非回目标，降低换手）。
- **FIFO 批次成本**：持仓账户逐批配对明细（买入日/数量/单位成本/剩余成本）、逐笔已实现收益与按年汇总、持有天数；尾差严格吸收（Σ配对回款=净回款、Σ配对成本=批次成本），历史缺口显式披露。分析视角，账面仍为平均成本法。

**⚡ 万级流水性能（v0.8）**
- 统计快照缓存：净资产/月报按数据指纹记忆化，任何过账、估值、汇率、账户口径变化自动失效；10k 交易冷算 2.3s → 暖调用 ~40ms。
- SQL 聚合下推 + 热路径索引（余额合计在 SQLite 端完成；超大金额自动回退 Dart 精确折叠，金额链路仍是 BigInt）。
- isolate 导入：万行级微信/支付宝账单的 GBK 解码与解析移出 UI 线程，界面不卡顿。

**🛡️ 情景模拟与 FIRE 规划（v0.7 新增）**
- **情景模拟（现金压力测试）**：失业 3 个月/收入降三成/工资延发/支出激增/一次性大额支出/额外月支出——组件可自由组合叠加，与基线现金预测同引擎重放对比：低谷加深多少、现金哪天耗尽、新增哪些缺口、情景是否可承受；只读模拟，不写账本。
- **FIRE 财务独立规划器**：FI 门槛（年支出 ÷ 提取率）、达标年数（有理数精确逐月复利，目标随通胀增长）、反解"想 N 年达标每年要存多少"、收益 ±1pp × 支出 ±10% 敏感性 3×3；参数从真实账本预填（可投资净资产 = 净资产 − 固定资产 − 长期权益，储蓄/支出取近 12 个月实绩）。
- **蒙特卡洛提取期生存率**：达标后按 4% 类法则提取 30 年，1000 条随机实际收益路径（Box-Muller + 固定种子可复现）测生存率与期末余额分位；全程在"年支出倍数"空间运行，金额不经过 double。

**🧭 人生规划 · 我的通胀 · 预算预警（v0.11 新增）**
- **人生规划器**：买房（等额本息月供闭式）/育儿（大学加成）/收入跳变/退休/大件/一次性六类事件自由组合，逐月有理数精确推演未来 20–50 年现金流与净资产——"首付+贷款=房价时买房瞬间净资产不变"等恒等式由测试锁定；现金耗尽风险年份、新增贷款总利息、净资产曲线一屏可见，参数从真实账本预填。
- **我的通胀**：用你自己的消费篮子算个人 CPI（固定篮子 Laspeyres）——"维持原有生活结构，现在要多花多少"，年化率 + 贡献分解，消费结构剧变时显式披露覆盖率。
- **预算执行预测**：月中按配速外推月底支出，超支预警 + 剩余日均可花建议。

**🎨 打磨与深色完整（v0.10 新增）**
- 外观设置：跟随系统 / 浅色 / 深色，立即生效；图表调色板与语义色全面令牌化，深色模式下九色配置、交易图标、饼图层次清晰可辨。
- 手机底部导航重构为 4 个高频目的地 + "更多"弹层（预算/计划/目标/负债/设置），并修复非首页时选中态错乱的问题。

**行情 / 汇率抓取（v0.4 AI + v0.6 直连官方源）**
- **直连官方源（推荐）**：腾讯行情（A股/场内基金，GBK）、stooq（港股/美股）、frankfurter（欧央行汇率）——免费无 key、秒回、一手数据；A股 6 位代码自动判交易所，汇率经 EUR 有理数交叉精确换算。
- **AI 联网搜索（兜底）**：配置主流 AI 服务（智谱 GLM——glm-4-flash 免费、Kimi、通义千问、DeepSeek、OpenAI、Anthropic、任意 OpenAI 兼容端点），API Key 加密存本地，直连查不到的再兜底。
- 两种模式统一**逐条预览**（价格/日期/来源/币种核对）→ 确认才入账，来源标记 `direct` / `ai:模型` 可审计；持仓账户详情可改行情代码（不动任何账目）。
- 出网安全守卫（仅 http/https，拒绝内网/环回地址）；无论哪种模式都只发送证券代码/名称与币种对，绝不发送余额与金额。

**安全**
- 数据库、备份全程加密；主口令 Argon2id/PBKDF2 派生 KEK 包裹随机 DEK，改口令不动数据；恢复码自救；自动锁定时长可设（1–60 分钟）；备份为认证加密容器 `.asbk`，错口令/损坏一律拒绝且不触碰原库。

**导入导出与去重**
- **微信/支付宝原生账单（v0.3）**：导出 CSV（GBK/UTF-8）自动识别列名，无需改表头；交易单号作稳定 ID，跨文件/重叠导出幂等；退款与不计收支流水按原因跳过并披露。
- 通用 CSV 四步向导：选文件 → 选账户 → 去重预览 → 智慧分类入账。
- 流水一键导出明文 CSV（UTF-8 BOM，Excel 直接打开）——数据自由。

## 快速开始

```bash
flutter pub get
dart run build_runner build --delete-conflicting-outputs   # 生成 drift 代码
flutter analyze                                            # 零 issue（CI 门禁）
flutter test                                               # 229 个测试
flutter run -d windows                                     # 或 android/ios
```

首次启动：设定主口令 → **离线保存恢复码** → 新建账户 → 记期初余额 → 开始记账。

> 数据库加密依赖 pubspec 中 `hooks.user_defines.sqlite3.source: sqlite3mc`
> （SQLite3MultipleCiphers）。国内网络可配置
> `FLUTTER_STORAGE_BASE_URL=https://storage.flutter-io.cn`、
> `PUB_HOSTED_URL=https://pub.flutter-io.cn` 镜像。
> 应用默认完全离线，全部功能免费，无任何付费/网络依赖。

## 已知限制（v0.10）

- 微信/支付宝解析器为通用模板实现，需按真实脱敏样本校准列映射（见 docs/07）。
- 多币种归因中，流量按期末汇率折算，汇兑影响与残余差额合并披露（docs/05 §4）。
- sodium 套件（Argon2id）已实现但默认未启用，待各平台原生构建验证后切换（docs/06 §6）。
- 同步/多设备为阶段 3 目标，当前单机（docs/10）；移动端生物识别解锁在路线图。

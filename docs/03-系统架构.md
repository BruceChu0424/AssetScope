# 03 · 系统架构

## 1. 分层与依赖规则

```
ui ──→ app(providers) ──→ services ──→ data(repositories) ──→ data(drift)
 │                              │
 └──────────────┬───────────────┴──→ domain（纯 Dart，零第三方依赖）
                ↓
             security
```

铁律：**箭头只能向左**。domain 不 import 任何其他层；services 组合 domain 与 data；ui 只经 providers 触碰 services。

| 层 | 目录 | 职责 | 测试 |
|---|---|---|---|
| domain | `lib/domain` | 金额/汇率/账本/债务/预测/预算/归因/去重的纯函数与实体 | 60 个单测，无平台依赖 |
| security | `lib/security` | CryptoSuite 抽象、KeyManager、备份容器 | 9 个单测（纯 Dart 套件） |
| data | `lib/data` | Drift 表、加密打开、仓储（Row↔实体映射） | 3 个集成测（内存库） |
| services | `lib/services` | 用例编排：过账、统计、预测、导入、备份 | 经 data 测试间接覆盖 |
| app | `lib/app` | 金库会话、自动锁定、路由、主题 | 手测 |
| ui | `lib/ui` | 9 页面 + 通用组件 | 手测（阶段 2 补 widget 测试） |

## 2. 关键设计决策

### 2.1 金额：BigInt 最小单位 + 有理数比例
- 金额 = `BigInt` 最小单位（CNY 分；BTC 8 位），**全链路无 double**。
- 汇率/利率/归属比例/持仓数量 = `Rational`（BigInt 分子/分母），仅在图表/进度展示时 `asDouble()`。
- 舍入：账内 halfEven（银行家舍入），展示 halfUp；所有舍入显式。

### 2.2 复式记账：签名分录 + 双账本
- 分录 `Posting`：**正=借、负=贷**；每笔交易的货币分录按币种分组求和必须为 0（`LedgerMath.checkConservation`，仓储过账前强制）。
- 持仓走**数量账**（数量分录单边：买入 +q / 卖出 −q），货币守恒由"成本镜像账户"承接：每个持仓账户配一个系统资产账户（`sys:cost:<code>`，不计净资产）。由此推出归因恒等式（docs/05 §3）。
- 15 种交易类型的分录构造**只**经 `TxBuilders`，禁止手写 Posting——口径规则集中一处。

### 2.3 状态与生命周期
- `vaultProvider`（Riverpod Notifier）持有会话：未初始化 → 锁定 → 解锁（含 db+repos+services）。
- 解锁 = 主口令/恢复码 → KDF → 解包 DEK → `PRAGMA key` 打开数据库。锁定 = 关库 + 置空 DEK。
- go_router 按"是否解锁"重定向到 `/lock`；任何指针活动重置 5 分钟自动锁定计时。

### 2.4 统计的正确性策略
- 余额/归因全部由**分录重算**（快照表仅缓存已关账月），补录历史自动修正后续月份。
- 每月净资产归因七分量互斥，解释不了的部分显式进"待核对差额"，绝不摊派隐藏。

## 3. 关键流程

### 3.1 记一笔（消费）
```
UI 表单 → TxBuilders.expense(构造分录) → LedgerRepo.post
        → checkConservation（不守恒即拒绝）
        → 事务写入 transactions + postings → 流水流(refresh)
```

### 3.2 月报
```
StatsService.monthReport(y, m)
 ├─ netWorthAt(上月末) / netWorthAt(本月末)      ← 分录+估值+汇率重算
 ├─ postingSumsBetween(分类/系统账户分录合计)
 ├─ 未实现 U(t) = Σ持仓(市值−成本) 于月初/月末
 ├─ fxEffect = 期初外币头寸×汇率变动 + 换汇账户净额
 └─ MonthAttributor.compute → 恒等式 + 残差
```

### 3.3 备份
```
sqlcipher_export → 明文临时库 → AEAD 容器(独立口令) → .asbk
恢复：容器解密 → 临时明文库 integrity_check → ATTACH KEY 新密钥导出 → .bak 后替换
```

## 5. 性能

个人账本规模（万级交易）：所有统计为毫秒级全量重算；导入与统计若超 1s 再引入 isolate（接口已按纯函数设计，可直接 `compute()`）。

# 12 · 共享组件与工具库索引

本文是**可查阅、可学习**的共享代码索引：写新页面前先看这里，避免重复造轮子。
目录约定：可复用组件一律进 `lib/ui/widgets/`，页面只从 `common.dart`（桶文件）导入。

## 1. 设计令牌（lib/ui/theme/app_theme.dart）

| 令牌 | 用途 |
|---|---|
| `AppColors.evergreen / brass / ink / paper` | 品牌基色：深祖母绿/暖铜金/墨色/暖纸底 |
| `AppColors.positiveOf(b) / negativeOf(b) / brassOf(b)` | 语义色（自动适配明暗模式） |
| `AppChartPalette.of(b)` / `.light` / `.dark` | 图表九色调色板（双模式，深色逐档提亮）；图表/图例取色唯一入口 |
| `signColor(minor, brightness)` | 正负金额着色的**唯一入口** |
| `AppRadii.card/chip/sheet` | 圆角（14/10/20） |
| `AppSpace.screenH/cardH/gap` | 间距刻度 |
| `buildAppTheme(brightness)` | 明/暗 ThemeData 构建（app.dart 使用） |

规则：UI 代码禁止散落硬编码颜色；语义色一律走 `xxxOf(brightness)`，
图表取色一律走 `AppChartPalette.of(brightness)`（配置桶用
`allocationColor(cls, b)`，见 reports/allocation_card.dart）。

统一从 `package:assetscope/ui/widgets/common.dart` 导入。

| 组件/函数 | 文件 | 用途与用法 |

| `MoneyText(minor, currencyCode:, size:, colorBySign:, sign:)` | money_text.dart | 金额文本组件；`MoneySize.xl/lg/md/sm` 四档；内置 tabular figures |
| `SectionCard(title:, trailing:, child:)` | section_card.dart | 区块卡片骨架（发丝线描边 + 标题行） |
| `StatRow(label:, value:, emphasized:, valueColor:)` | section_card.dart | "标签—数值"行（列表/详情页通用） |
| `AmountTile(label:, amount:, hint:, color:)` | section_card.dart | 多列统计瓦片（一 Row 放 2–3 个） |

| `AppDateField(controller:)` | fields_and_badges.dart | 日期域（点击弹日历） |
| `confirmDialog(ctx, title:, message:, confirmLabel:, destructive:)` | fields_and_badges.dart | 危险操作确认的统一入口 |
| `RationalDisplayX.toDecimalString(digits)` | rational_display.dart | Rational → 截断小数字符串（数量/费率展示） |

### 典型组合

```dart
SectionCard(
  title: '本月收支',
  child: Row(children: [
    Expanded(child: AmountTile(label: '收入', amount: fmtMinor(income, base))),
    Expanded(child: AmountTile(label: '消费', amount: fmtMinor(expense, base))),
  ]),
)
```

金额要么 `fmtMinor(...)`（纯文本处），要么 `MoneyText(...)`（要语义色/字号处）；
禁止手写 `toString()/100` 之类的展示。

## 7. 何时新建共享组件

- 同样的 UI 片段在 ≥2 个页面出现 → 提取进 `widgets/`，并更新本文档。
- 单文件 >400 行 → 按职责拆（页面骨架 / 弹层 / provider 各自成文件）。
- 命名：组件 PascalCase、函数 camelCase `showXxx`、provider xxxProvider。

## 8. Widget 测试公共 harness（test/ui/widget_host.dart）

写新页面的 widget 测试时复用：`widgetDb()`（内存库）、
`buildWidgetSession(db)`（与 providers._openDatabase 同构的全服务栈会话）、
`seedWidgetData(s)`（招行账户 + 本月 3 消费 1 收入 + 月度房租计划，
金额与对手方被断言引用，改动需同步测试）、`FixedVault`（固定已解锁）、
`widgetHost(child, session)`（ProviderScope + 浅色 MaterialApp）。
工艺注意（沿用 v0.9 经验）：输入框光标闪烁与 drift watch 流关闭的
Timer 需要结尾 unfocus + `pumpWidget(SizedBox)` + 泵帧消化；
动画页（地球）不能 pumpAndSettle。

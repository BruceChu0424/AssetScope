# 12 · 共享组件与工具库索引

本文是**可查阅、可学习**的共享代码索引：写新页面前先看这里，避免重复造轮子。
目录约定：可复用组件一律进 `lib/ui/widgets/`，页面只从 `common.dart`（桶文件）导入。

## 1. 设计令牌（lib/ui/theme/app_theme.dart）

| 令牌 | 用途 |
|---|---|
| `AppColors.navy / brass / ink / paper` | 品牌基色：墨蓝/香槟金/蓝墨/冷雾白底 |
| `AppColors.positiveOf(b) / negativeOf(b) / brassOf(b)` | 语义色（自动适配明暗模式） |
| `AppChartPalette.of(b)` / `.light` / `.dark` | 图表九色调色板（双模式，深色逐档提亮）；图表/图例取色唯一入口 |
| `signColor(minor, brightness)` | 正负金额着色的**唯一入口** |
| `AppRadii.card/chip/sheet` | 圆角（14/10/20） |
| `AppSpace.screenH/cardH/gap` | 间距刻度 |
| `buildAppTheme(brightness)` | 明/暗 ThemeData 构建（app.dart 使用） |

规则：UI 代码禁止散落硬编码颜色；语义色一律走 `xxxOf(brightness)`，
图表取色一律走 `AppChartPalette.of(brightness)`（配置桶用
`allocationColor(cls, b)`，见 reports/allocation_card.dart）。

### 典型组合

```dart
// 页面骨架（v0.22 起唯一入口）：大屏标题带+居中内容列，小屏 AppBar。
PageFrame(
  title: '预算',
  maxWidth: 980,
  actions: [ActionIcon(tooltip: '…', icon: Icons.compare_arrows, onTap: …)],
  fab: …, // ParticleEdge 包 FAB
  child: ListView(children: [
    StatBand(items: [StatBandItem('剩余', fmtMinor(v, base))]), // 页首统计带（数值老虎机滚动）
    CardWrap(tileWidth: 460, children: [ /* 信封卡… */ ]),      // 定宽网格（自动 hover 抬升）
  ]),
)

// 区块卡：
SectionCard(
  title: '本月收支',
  child: Row(children: [
    Expanded(child: AmountTile(label: '收入', amount: fmtMinor(income, base))),
    Expanded(child: AmountTile(label: '消费', amount: fmtMinor(expense, base))),
  ]),
)
```

金额要么 `fmtMinor(...)`（纯文本处），要么 `MoneyText(...)`（要语义色/字号处；
读数型场景加 `roll: true` 走老虎机逐位滚动）；禁止手写 `toString()/100` 之类的展示。
首页卡片直进对应页走 `HeroLaunch.go(context, path, cardKey)`（容器展开转场）。

## 7. 何时新建共享组件

- 同样的 UI 片段在 ≥2 个页面出现 → 提取进 `widgets/`，并更新本文档。
- 单文件 >400 行 → 按职责拆（页面骨架 / 弹层 / provider 各自成文件）。
- 命名：组件 PascalCase、函数 camelCase `showXxx`、provider xxxProvider。

## 9. 设计与动效工作流（AI 协作规范）

凡 UI 任务（新页面、页面改版、新共享组件），AI 协作时三个 skill 必须组合使用，
缺一不可（2026-10 起，用户明确要求——"UI 设计的好看，动画也要设计好用"）：

| Skill | 使用时机 | 职责 |
|---|---|---|
| `frontend-design` | 动手写 UI 前 | 定视觉方向：排版、层级、留白；配色仍必须走 §1 设计令牌，避免模板化默认样式 |
| `find-animation-opportunities` | 布局成型后 | **只读**盘点哪些交互值得加动效、哪些不该加（拒绝噪音动画）；产出带精确数值（曲线/时长/属性）的提案 |
| `animate` | 实现动效阶段 | 按固定顺序落地：该不该动 → 目的 → 工具 → 属性 → 曲线时长 → 打断行为 → 退场 |

**动效强度（2026-10-29 用户指令，覆盖 skill 默认的克制姿态）**：
「不用减少动画——电脑性能足够好，要酷炫好看，各种动画/粒子动画可以加的都加」。
本项目动效按**丰富优先**执行：粒子（星尘/爆发/火花）、星空流星、辉光呼吸、
hover 弹性过冲（easeOutBack）、数字滚动计数等均属欢迎范围；每帧多 painter、
常驻 repeat controller 不构成拒绝理由。底线不变：配色走 §1 令牌；
`MediaQuery.disableAnimationsOf`（系统无障碍）仍尊重；纯阅读数据不加干扰性抖动；
常驻动画页测试不能 pumpAndSettle（§8）。

**标题与提示语（2026-10-29 用户指令，长期硬规范）**：
前端界面不得把副标题、说明文字、提示语句作为静态文本直接铺在页面上。
需要解释某标题/某块内容的含义时，在标题旁（或对应位置）放一个小
icon（info/help 类），鼠标悬停（触屏长按/点击）弹出提示内容——
Flutter 统一用 `Tooltip` 或 §5 既有弹层。页面默认可见的只有标题本身
与数据。每次 UI 任务（新页面、改版、新组件）都要执行此规范。

**加载与错误（2026-10-29 用户指令，长期硬规范）**：
- 任何长任务的「加载中」**一律** `runBusy(context, message:, origin:, task:)`
  一行接入——烟雾粒子舞台自动呈现（粒子自触发按钮如烟喷发 → 汇聚成
  品牌 A 标 → 行波涟漪，成功烟团迸散 / 失败染朱砂自动处理），**不要
  新造任何 loading 弹窗、遮罩、转圈组件**；
- 调用点有触发按钮时**必传 `origin:`**（按钮中心全局坐标：GlobalKey +
  `RenderBox.localToGlobal`），粒子才会从按钮喷出；无按钮场景省略
  （默认自下方涌起）；
- 深色场景的小内联加载（不适合全屏遮罩处）才用 `OrbitSpinner`；
- 表单错误一律「顶部通知（`showTopNotice`）+ 输入框红框加粗 + 横摇」
  三件套，**禁止在输入框下方内联展示错误文字**；
- 品牌时刻的 logo 一律 `ParticleBrandMark(size:)` 粒子形态（同 300
  目标点表，与加载舞台同视觉语言），不用静态 `BrandMark`。

**交互粒子（2026-10-29 用户指令，长期硬规范）**：
所有按钮、卡片、输入框的「进行中」反馈一律粒子化，且**只准复用
`ParticleEdge` 家族，不得另写 hover/聚焦粒子**：
- 新主行动钮写 `ParticleFilledButton`（或 `.icon`），不写裸 `FilledButton`；
- 新输入框写 `ParticleTextField`（聚焦光尘 + 输入迸发），不写裸 `TextField`；
- 卡片直接用 `SectionCard`（内置 hover 光尘）；非 SectionCard 的卡/钮
  自行包 `ParticleEdge(child: ...)`，自有 hover 态的组件用
  `ParticleEdge.active(active: hover)` 复用既有检测；
- 密集小图标钮（工具条 IconButton）不加粒子——密度场景以标准 hover
  态为准，避免光尘泛滥稀释主体。

**循环动画必须无缝（2026-10-30 用户指令，长期硬规范）**：
一切循环/往复动画在周期边界**不得有可见跳变**——"转一圈半再咔回开头"
是缺陷。写法三选一：① 旋转类每周期恰为 2π 整数倍（OrbitSpinner）或
用单调时钟纯函数（ParticleOrbit/光尘/星野，无回绕）；② 包络类用两端
归零的函数（`sin(phase·π)`、`0.5-0.5·cos(v·2π)`——呼吸环/光环），
禁止 `(1-t)` 线性包络（回绕处瞬跳）；③ 有生灭的粒子（微尘上浮等）
在出入画面的边缘加钟形淡入淡出，或让回绕发生在画面外。新增循环动效
须按此自查 t=0 与 t=1 状态连续。

**数值变化滚动（2026-10-30 用户指令，长期硬规范）**：
读数型数值变化（金额/统计）不做瞬切，也不自造滚动——金额用
`MoneyText(..., roll: true)`，任意文本用 `Odometer(text:, style:)`
（老虎机逐位滚动，工艺见 §2 表）；刷新/插值驱动的连续变化直接喂文本，
Odometer 自带连续重定向续走。

硬约束：动效颜色仍走 §1 语义色入口，不得硬编码；沉淀出的共享动效组件进 `widgets/`
并回写本文档索引。

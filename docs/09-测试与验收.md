## 2. 验收硬规则 ↔ 测试映射

| 验收要求 | 测试 |
|---|---|
| 同笔微信/支付宝与银行卡记录只统计一次 | dedup: 转账配对 + externalId 幂等 + data: 外部 ID 二次拒绝 |
| 转账不变成收入或消费 | ledger_kinds: 转账不影响收支 |
| 信用卡消费后还款不重复记账 | ledger_kinds: 信用卡消费即确认+还款不再确认 |
| 贷款本金和利息拆分正确 | ledger_kinds: 还本拆分 |
| 已计提利息付款不重复计费 | 口径设计（利息仅支付时确认）+ loan: 先息后本 |
| 证券以前浮盈卖出不重复增加收益 | attribution: 浮盈卖出只计一次（恒等式钉死） |
| 预算/计划/准备金/实际付款不重复扣减 | projection: 准备金单扣（释放机制） |
| 月底有钱但月中缺钱能识别 | projection: 月中缺钱 |
| 历史补录不重复修改真实余额 | ledger_kinds: 期初余额走权益；data: 一月末余额不含五月 |
| 旧估值、缺失数据清楚显示 | stats: missingValuations/stale 计数（UI 待处理卡）+ 估值缺失不计 0 |
| 数据库/备份泄漏时内容保持加密 | crypto: 容器拒绝 + 头部无 DEK 明文 |
| 损坏备份、错误口令不破坏原库 | crypto: 错口令/截断/魔数破坏全拒绝；backup service 隔离校验流程 |
| 换设备恢复后一致 | data roundtrip + backup docs §4 流程（真机人工验收） |
| 核心功能离线可用 | 架构零网络（人工验收） |

## 3. 人工验收清单（真机，发布前执行）

1. Windows/Android 各完成一次：建库→记 10 笔混合交易→月报核对→备份→清数据→恢复→一致。
2. 数据库文件用十六进制编辑器抽查：无明文账户名/金额。
3. `PRAGMA cipher` 非空（构建变体自检）。
4. 锁定后 5 分钟无操作自动回锁屏；锁定后任务管理器杀进程重启需口令。
5. 微信/支付宝脱敏样本各一份：解析→预览建议→确认→重复导入幂等。
6. 期初补录上月资产 → 本月月报不出现该金额为收入；归因残差为 0。
7. 导出的 .asbk 在另一台设备用备份口令恢复成功。

### 4a. 测试工艺坑（v0.23 增补，踩过即录）

- **自定义输入组件透传 `maxLines` 必须默认 `= 1`**：原生 `TextField`
  构造默认就是 1；包装件若显式传 null，`obscureText` 场景触发断言
  「Obscured fields cannot be multiline」——锁屏/first_run 全崩，golden
  里表现为 ~13% 黄黑溢出条纹。`ParticleTextField` 已钉死（docs/12）。
- **golden 走查基线随页面改动漂移是常态**：页面代码改动后
  `redesign_walkthrough_test` 报 0.0x% 像素差 → 确认差异属预期改动后
  `flutter test test/ui/redesign_walkthrough_test.dart --update-goldens`
  重生成基线；分析差异位置用 failures/ 下 masterImage/testImage 像素
  逐行对比（PIL ImageChops）。
- **崩溃的 flutter_tester 会锁住 build/native_assets 的 sqlite3mc.dll**
  （下次 flutter test 工具级崩溃"Deletion failed, errno=5"）：先
  `taskkill //IM flutter_tester.exe //F` 再跑。
- **`find.byTooltip(...)` 收 Pattern 不收 Matcher**（匹配提示文案用
  `RegExp('...')`）。
- **多会话并行开发时严禁 `git stash`**：会把并行会话的未提交工作一起
  卷走，且 pop 常被 flutter 自动再生成的 `windows/generated_plugin_*
 产物阻塞（需先 checkout 这两个文件再 pop）——验证基线请用冻结快照
  沙箱（robocopy 到 %TEMP%）而非 stash。

# 02 · 开源调研与选型

调研时间：2026-10。结论先行：**没有任何一个现成项目同时满足"全资产 + 账务正确 + 本地加密"三项**，因此采用**自建 Flutter 财务核心 + 复用成熟基础组件**的路线，并把候选项目的优秀设计吸收进领域层。

## 1. 候选项目评估

| 项目 | 现状 | 对本项目的价值 | 结论 |
|---|---|---|---|
| **Monekin**（Flutter） | 活跃；README 列明账户、净资产、债务、预算、目标、多币种、周期交易 | 最接近的 Flutter 全资产候选 | **不整体二开**：其数据库初始化与备份导出路径未见应用层加密封装（密钥初始化/备份加密封装缺失），安全改造成本 ≈ 重写核心；账务口径与本项目验收清单差异大。吸收其账户类型建模与交互。 |
| **Sure**（Maybe 社区延续） | 活跃；全资产总览、多币种 | 产品形态与数据模型参考 | **参考**：Flutter 端仅覆盖登录/余额，完整体验在 Web。 |
| **Firefly III**（PHP） | 成熟稳定 | 复式记账、规则引擎、周期交易、导入对账体系 | **参考**：借贷方向、自动规则、导入预览流程映射到本项目 TxBuilders 与导入管线。 |
| **Actual Budget** | 活跃 | 预算信封思想 | **参考**：不原生支持多币种，不能直接当全资产账本。 |
| **Cashew**（Flutter） | 活跃 | 记账交互体验 | **参考**。 |
| **Portfolio Performance**（Java） | 成熟 | 投资收益口径（TWR/MWR、已实现/未实现拆分） | **直接吸收算法口径**，实现于 `domain/invest/returns.dart`。 |

原版 **Maybe** 已于 2025-07 归档，不再考虑。

## 2. 三条路线对比（决策记录）

| 路线 | 工作量 | 风险 | 决策 |
|---|---|---|---|
| 整体二开 Monekin | 中 | 加密改造 + 口径重构双线作战，测试体系需重建 | ✗ |
| 复用部分模块 | 中 | Flutter 项目间抽模块成本高、耦合 UI | ✗（组件级复用 ✓） |
| **自建核心 + 复用组件** | 中高（已投入） | 可控：核心算法自研并有测试钉死 | ✓ |

## 3. 组件级复用清单（全部 MIT/BSD-3 宽松许可）

| 组件 | 用途 | 许可证 |
|---|---|---|
| drift 2.35 | 类型安全 SQL、事务、迁移 | MIT |
| sqlite3 3.5（build hook: sqlite3mc） | SQLite3MultipleCiphers 加密引擎 | MIT |
| riverpod 3.4 | 状态管理 | MIT |
| go_router 17.5 | 导航与守卫 | BSD-3 |
| fl_chart 1.2 | 净资产走势/构成图 | MIT |
| sodium 4.0（sumo） | Argon2id + XSalsa20-Poly1305（原生，待启用） | BSD-3 |
| cryptography 2.9 | XChaCha20-Poly1305 + PBKDF2-HMAC-SHA512（纯 Dart 兜底/测试） | BSD-3 |
| flutter_secure_storage 11 | 平台安全存储（预留） | BSD-3 |
| fast_gbk | 微信/支付宝 GBK 账单解码 | MIT |
| intl / uuid / path(_provider) / file_selector | i18n、ID、路径、文件选择 | BSD-3 |

> 版本以 pubspec.lock 为准；升级 drift 需重新验证 `hooks.user_defines.sqlite3.source: sqlite3mc` 仍生效（`PRAGMA cipher` 非空）。

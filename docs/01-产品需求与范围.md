# 01 · 产品需求与范围

## 1. 产品定位

**资观 AssetScope** 是给单人（或未来的家庭账本）长期使用的本地个人财务系统。它不是记账软件的流水清单，而是一个"每月看一眼就知道自己状态"的仪表盘 + 一套保证算得对的账本。

优先级（冲突时从上往下取舍）：

1. **账务和统计正确**
2. 数据安全与恢复能力
3. 使用清晰方便
4. 自动化
5. 视觉表现

## 2. 首页必须回答的十个问题

| # | 问题 | 对应功能 |
|---|---|---|
| 1 | 总资产、总负债、净资产多少？ | 净资产卡（含各账户构成） |
| 2 | 哪些钱能立即用，哪些受限？ | 账户流动性标注（0/1/30/90/长期天） |
| 3 | 本月收入、消费、费用、结余？ | 月度收支卡 |
| 4 | 本月还了多少本金、付了多少利息？ | 月报债务区（loanRepay 拆分） |
| 5 | 净资产为什么变多变少？ | 归因分解（互斥分量 + 待核对差额） |
| 6 | 每月固定开销、未来已安排支出？ | 计划页 + 未来 30 天列表 |
| 7 | 预算还剩多少？覆盖既定计划后还能花多少？ | 预算信封 + 可支配上限 |
| 8 | 未来 7/30/90 天会不会资金不足？ | 现金预测（含单账户缺口） |
| 9 | 各资产/负债/开销过去一年怎么变？ | 净资产 12 个月走势 + 月报历史 |
| 10 | 哪些账目、估值、计划还没处理？ | 首页"待处理"（缺估值/估值过期/待核对差额） |

## 3. v0.1 范围（已实现）

- 资产与负债账户体系（22 种资产子类型、9 种负债子类型、3 种估值方式）
- 复式记账核心（15 种交易类型构造器 + 守恒校验）
- 期初余额、对账调整（历史修正单列，不进当期收支）
- 贷款合同与还款计划（5 种还款方式 + 提前还款模拟 + 策略对比 + 有效年化）
- 周期计划（每周/每两周/每月/每季/每年/自定义/单次；月末与闰年规则；跳月；金额覆盖）
- 预算（总预算/分类预算；已花/已计划/剩余）
- 目标准备金（缺口、每月需存、预留释放）
- 现金预测（90 天逐日；准备金释放；单账户缺口；可支配上限）
- 月报与净资产归因（七分量互斥分解 + 残差）
- 加密数据库 + 主口令/恢复码 + 自动锁定 + 加密备份/恢复
- 通用 CSV 导入（UTF-8/GBK）+ 去重管线
- 中文本位 UI（Windows/Android/iOS）

## 3a. v0.23 新增 · AI 能力（用户自己的 Key，零后端）

- **每日 AI 资产估值**：房产/车辆等可开启每日自动检索真实市价更新
  资产价值（权威源交叉、剔除营销报价、可审计、人工纠正当日优先）。
- **地址精确定位**：详细地址（小区/楼栋）自动转经纬度（AI 地理编码）。
- **AI 助手**（导航「AI 助手」）：多轮对话，可携带账本概况汇总回答
  财务问题。
- **用量与额度**：设置里看 AI 调用统计与服务商余额。
- 边界：发送范围逐能力列明（docs/06 §7），逐笔流水与账户编号永不外发。

## 4. 明确不在 v0.1 的

- 银行/券商自动同步（需逐一验证可用授权接口；v0.1 只导入+手动）
- 多设备同步（阶段 3：客户端加密同步）
- 附件/图片票据（表结构预留，UI 未做）

> 其中两项后来以**用户自带 AI Key**的形态实现（见 §3a）：行情/汇率
> 联网抓取（v0.4/v0.6 直连）与 AI 能力全家桶（v0.23）——数据只发往
> 用户自己配置的服务商，默认零网络不变（docs/06 §7）。

## 5. 默认假设（可设置）

| 项 | 默认值 | 修改位置 |
|---|---|---|
| 界面语言 | 中文 | — |
| 本位币 | CNY | 设置页 |
| 统计时区 | 本地时区 | — |
| 月份区间 | 自然月（1 日–月末） | 阶段 2 支持自定义月薪日 |
| 统计范围 | 个人（归属比例 100%） | 账户归属比例字段已预留 |
| 自动锁定 | 5 分钟无操作 | 阶段 2 做成设置项 |
| 预测期 | 90 天（含今天） | 代码常量 |
| 现金底线 | 0 | settings.baselineMinCashMinor |
| 利息确认口径 | 收付实现制（支付时确认） | docs/05 §2 |
| 投资费用口径 | 费用资本化进成本 | docs/05 §3 |

## 6. 非目标

- 不做多人协作编辑（家庭账本走"归属比例"或阶段 3 的只读共享）
- 不做税务申报计算
- 不承诺防范"设备被植入键盘记录器"类攻击（见 docs/06 威胁模型）

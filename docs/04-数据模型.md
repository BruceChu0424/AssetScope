# 04 · 数据模型

## 1. 存储通则

- 金额：`TEXT`（BigInt 最小单位十进制字符串）——加密资产 8 位小数也不溢出。
- 比例/利率/单价：分子/分母两个 TEXT 列（精确有理数）。
- 日期：drift `dateTime()`（文本 ISO）；交易日仅取年月日。
- 币种：ISO 代码 TEXT，注册表见 `domain/money/currency.dart`。
- 枚举：存 `name` 字符串，升级安全。

## 2. 表一览（schemaVersion = 1）

| 表 | 主键 | 说明 |
|---|---|---|
| accounts | id | 账户=资产/负债/分类/权益统一实体；22 种资产子类型、9 种负债子类型；含归属比例、流动性（由子类型推导）、估值方式、信用额度（仅元数据）、成本镜像指针 |
| securities | id | 证券代码/名称/类型/计价币种 |
| transactions | id | 交易头：日期、kind/status/source、分类、对手方、externalId（导入幂等）、isAdjustment |
| postings | 自增 | 分录：txId、accountId、金额或（securityId+数量）；正=借 负=贷 |
| budgets | id | 总/分类预算、起止月、结转策略与上限 |
| scheduled_events | id | 固定/预定支出：周期、锚点、金额或区间、月末策略、跳月 JSON、金额覆盖 JSON |
| goals | id | 目标：金额、日期、优先级、已预留、注资账户 |
| debt_contracts | liabilityAccountId | 利率（十进制串）、还款方式、期数、起息/首个还款日、月费、计息基准、提前还款费率 |
| valuations | 自增 | 持仓单价（有理数）或手工总值；source、note |
| fx_rates | 自增 | base→quote、日期、有理数汇率、来源 |
| snapshots | month | 已关账月缓存（payload JSON） |
| import_batches | id | 导入批次：来源、文件名、解析器版本、计数 |
| settings | key | baseCurrency、lockTimeout、predictionHorizon、baselineMinCash |

索引：postings(txId/accountId)、transactions(date/externalId)、valuations(accountId,date) 由代码生成器默认提供 + 查询按需补充。

## 3. 系统账户（唯一实例）

| id | 类型 | 用途 |
|---|---|---|
| sys:equity:opening | equity | 期初余额权益（历史补录入口） |
| sys:equity:adjustment | equity | 对账调整 |
| sys:expense:fx | expense | 换汇两侧配平（余额揭示换汇成本） |
| sys:expense:rounding | expense | 尾差吸收 |
| sys:income:realized-pnl | income | 已实现投资损益（贷=收益） |
| sys:income:dividend | income | 股息分红 |
| sys:cost:<code> | asset（不计净资产） | 持仓成本镜像：买入借记成本、卖出按平均成本贷记 |

另有种子分类：支出 16 类（餐饮/交通/购物/居住/水电燃气/通讯网络/医疗/教育/娱乐/旅行/保险费/人情往来/利息费用/其他）+ 收入 4 类（工资/奖金/兼职/其他）。

## 4. 关键不变量（数据库层面保证）

1. **每笔交易每币种 Σ分录 = 0**（过账入口校验，违反拒绝写入）。
2. 持仓数量账净额 = 该账户数量分录累计和；卖出超持仓在服务层拒绝。
3. `sys:cost:*` 余额 = Σ买入含费成本 − Σ卖出结转成本，永远 ≥ 0。
4. 交易不可变：改错=作废（status=voided）+ 重记，保证余额重算确定性。
5. externalId 唯一性由"入库前查询"保证（幂等导入）。

## 5. 与领域实体的映射

仓储（`data/repositories/*`）双向映射 Row ↔ 领域实体，枚举按 name、比例按分子/分母、列表/字典 JSON 序列化。**服务层与 UI 永远拿领域实体，不碰 Row**。

# 05 · 账务口径与算法

本文是"算得对"的唯一权威定义。实现位置以代码为准，公式与口径以本文为准。

## 1. 记账方向

- 分录签名：**正 = 借，负 = 贷**。
- 资产/费用：借增贷减；负债/权益/收入：贷增借减。
- 展示余额：资产/费用取借方净额；负债/权益/收入取贷方净额（正数=欠款/已挣）。
- **每笔交易每币种借贷必相等**（守恒校验强制）。

## 2. 事件口径表（TxBuilders 唯一实现）

| 事件 | 分录（借+/贷−） | 口径要点 |
|---|---|---|
| 期初余额 | 借资产 +X / 贷权益−X | isAdjustment，不进当期收支；**补录旧资产不算新赚** |
| 收入 | 借资产 +A / 贷收入分类 −A | |
| 消费 | 借支出分类 +A / 贷支付账户 −A | 支付账户可为信用卡（负债）；**消费发生时即确认** |
| 退款 | 借资产 +A / 贷原支出分类 −A | 冲减当期消费；支持部分/多次/跨月 |
| 转账 | 借转入 +A / 贷转出 −A | 同币种；**收支为 0** |
| 换汇 | 借目标币 +B / 贷 sys:fx −B；贷源币 −S / 借 sys:fx +S | 两端保留实际金额；成本经 sys:fx 余额与归因披露 |
| 信用卡还款 | 借卡 +A / 贷现金 −A | **不再确认消费**（消费时已计） |
| 借款到账 | 借现金 +P / 贷负债 −P | **不是收入** |
| 贷款还款 | 借负债 +本 / 借利息费用 +息(+费) / 贷现金 −(本+息+费) | 本息费拆分；利息**支付时确认**（收付实现制），已计提未付利息只出现在预测——**支付时不重复计费** |
| 借出 | 借应收 +A / 贷现金 −A | 不是消费 |
| 收回借出 | 借现金 +A / 贷应收 −A | 不是收入 |
| 买入证券 | 借成本镜像 +(含费总额) / 贷现金 −(含费总额)；数量 +q | 费用**资本化**进成本，不进消费口径 |
| 卖出证券 | 借现金 +净回款 / 贷成本镜像 −(平均成本×q)；已实现损益 = 净回款−结转成本（收益贷记/亏损借记 sys:realized-pnl）；数量 −q | 平均成本法；**以前的浮盈不重复计入本期**（§3） |
| 分红 | 借现金 +D / 贷 sys:dividend −D | 投资收益，非普通收入 |
| 对账调整 | 借/贷账户 ±Δ / 权益调整 ∓Δ | isAdjustment；把账本对齐真实余额，差额单列 |

## 3. 净资产归因恒等式（核心）

```
期末净资产 = 期初净资产
  + 收支贡献        （收入 − 消费费用；消费在发生时确认）
  + 投资损益        = 已实现 + 分红 + ΔU，其中 U = Σ持仓(市值 − 成本)
  + 汇兑影响        = 期初外币头寸 × 汇率变动 + 换汇账户净额
  + 其他估值变化    （房产等手工估值变动）
  + 范围/历史修正   （期初补录 + 对账调整）
  + 待核对差额      （残差；应≈0，非 0 = 数据缺口，月报必须展示）
```

**为什么 ΔU 防重复**：卖出日，ΔMV = −市值(卖) 、ΔCB = −成本(卖)，故 ΔU 的变化恰为 −(已实现收益)；本期投资贡献 = 已实现 + ΔU = 只剩持有部分的价格变动。买入按市价成交时 U 不变，不产生虚假收益。该恒等式在纯 CNY 下严格成立（测试钉死）；多币种下流量按期末汇率折算，近似误差并入汇兑/残差披露。

## 4. 现金预测

```
C(t)  = Σ现金账户余额(折本位币, 流动性≤T天) + Σ事件(date ≤ t)
R(t)  = 准备金占用（目标预留+应急金；对应支出日自动释放，避免双扣）
B     = 额外最低现金底线
计划外可支配上限 = max(0, min_t [ C(t) − R(t) − B ])     t ∈ [今天, 今天+90天]
```

防重复扣减规则（全部有测试）：
- 期初余额已含预留现金 → R 只在公式里扣一次；
- 支付日 C 下降的同时 R 释放等额；
- 信用卡只按"还款流出"入预测（消费不再二次扣现金）；
- 已实际支付的计划由服务层过滤出事件列表；
- 同日多事件顺序未知 → **先流出后流入**（保守情景）；
- 总现金充足 ≠ 每张卡充足：逐账户独立检查缺口。

## 5. 债务算法

| 方式 | 每期 | 说明 |
|---|---|---|
| 等额本息 | A = P·i(1+i)ⁿ/((1+i)ⁿ−1)；本金 = A − 利息 | i = 名义年利率/12（国内惯例）；末期吸收累计舍入差 |
| 等额本金 | 本金 = P/n；利息 = 剩余×i | |
| 先息后本 | 利息 = P×i；末期还本 | |
| 固定分期(等本等费) | 本金 = P/n；费 = **原始本金**×i | 用 IRR 揭示真实年化（名义 7.2% 实际 ≈13%） |
| 免息 | 本金 = P/n | |

- 利率精确用 `Rational`，每期舍入到分。
- **有效年化** = 月度 IRR（现金流：期初 +P，每期 −(本+息+费)）×12（名义口径年化，XIRR 日期口径见 §6）。
- **提前还款**：按剩余本金与剩余期数重排（保月供缩期 / 保期限降月供），返回利息净节省（已扣手续费）。
- **雪崩 vs 雪球**：逐月模拟，月息 = 剩余×apr/1200；先付各笔最低还款，额外资金按策略注入；还清一笔后其最低还款滚入资金池。

## 6. 投资收益率

- **TWR（时间加权）**：r_k = (V_end − F_k)/V_start − 1，链乘 Π(1+r_k)。排除外部资金进出干扰，衡量投资能力。**组合边界约定：内部买卖不是外部流**。
  估值点取月末（近 13 个 + 今天）；任一在持仓缺价/缺汇率的时点整体作废，不作"缺价计 0"；有效点 <2 时返回 null。年化按估值点跨度实际天数复利。
- **XIRR（资金加权）**：实际/365 折现的 NPV=0，牛顿迭代 + 二分兜底；现金流同号/不收敛返回 null（显式"无法计算"而非编造数字）。
- 已实现损益 = 净回款 − 平均成本×数量（平均成本法）。
- 年度报告口径：总收支/储蓄率/储蓄月数 = 12 个月月报聚合（月报口径见 §3）；最大单笔消费按分类分录金额取全年最大。

## 7. 预算口径

- 消费发生即占用（信用卡消费占用、还款不占用；贷款本金不占用，利息按其口径占用）。
- 信封：剩余 = 额度 + 结转 − 已花 − 已计划 − 已预留。
- 结转策略：不结转 / 全额 / 上限；超支月不产生负结转（v1 只展示超支）。

## 8. 汇率

- 有理数精确（如 7.2 = 36/5）；换算 minor_out = minor_in × rate × 10^(d_to−d_from)，halfEven。
- 历史：取 ≤ 时点最近一条；缺失时该资产计 0 并计入"待处理"，**绝不假装有汇率**。

# 05 · 账务口径与算法

本文是"算得对"的唯一权威定义。实现位置以代码为准，公式与口径以本文为准。

## 1. 记账方向

- 分录签名：**正 = 借，负 = 贷**。
- 资产/费用：借增贷减；负债/权益/收入：贷增借减。
- 展示余额：资产/费用取借方净额；负债/权益/收入取贷方净额（正数=欠款/已挣）。
- **每笔交易每币种借贷必相等**（守恒校验强制）。

## 2. 事件口径表（TxBuilders 唯一实现）

| 事件 | 分录（借+/贷−） | 口径要点 |
|---|---|---|
| 期初余额 | 借资产 +X / 贷权益−X | isAdjustment，不进当期收支；**补录旧资产不算新赚** |
| 收入 | 借资产 +A / 贷收入分类 −A | |
| 消费 | 借支出分类 +A / 贷支付账户 −A | 支付账户可为信用卡（负债）；**消费发生时即确认** |
| 退款 | 借资产 +A / 贷原支出分类 −A | 冲减当期消费；支持部分/多次/跨月 |
| 转账 | 借转入 +A / 贷转出 −A | 同币种；**收支为 0** |
| 换汇 | 借目标币 +B / 贷 sys:fx −B；贷源币 −S / 借 sys:fx +S | 两端保留实际金额；成本经 sys:fx 余额与归因披露 |
| 信用卡还款 | 借卡 +A / 贷现金 −A | **不再确认消费**（消费时已计） |
| 借款到账 | 借现金 +P / 贷负债 −P | **不是收入** |
| 贷款还款 | 借负债 +本 / 借利息费用 +息(+费) / 贷现金 −(本+息+费) | 本息费拆分；利息**支付时确认**（收付实现制），已计提未付利息只出现在预测——**支付时不重复计费** |
| 借出 | 借应收 +A / 贷现金 −A | 不是消费 |
| 收回借出 | 借现金 +A / 贷应收 −A | 不是收入 |
| 买入证券 | 借成本镜像 +(含费总额) / 贷现金 −(含费总额)；数量 +q | 费用**资本化**进成本，不进消费口径 |
| 卖出证券 | 借现金 +净回款 / 贷成本镜像 −(平均成本×q)；已实现损益 = 净回款−结转成本（收益贷记/亏损借记 sys:realized-pnl）；数量 −q | 平均成本法；**以前的浮盈不重复计入本期**（§3） |
| 分红 | 借现金 +D / 贷 sys:dividend −D | 投资收益，非普通收入 |
| 对账调整 | 借/贷账户 ±Δ / 权益调整 ∓Δ | isAdjustment；把账本对齐真实余额，差额单列 |

## 3. 净资产归因恒等式（核心）

```
期末净资产 = 期初净资产
  + 收支贡献        （收入 − 消费费用；消费在发生时确认）
  + 投资损益        = 已实现 + 分红 + ΔU，其中 U = Σ持仓(市值 − 成本)
  + 汇兑影响        = 期初外币头寸 × 汇率变动 + 换汇账户净额
  + 其他估值变化    （房产等手工估值变动）
  + 范围/历史修正   （期初补录 + 对账调整）
  + 待核对差额      （残差；应≈0，非 0 = 数据缺口，月报必须展示）
```

**为什么 ΔU 防重复**：卖出日，ΔMV = −市值(卖) 、ΔCB = −成本(卖)，故 ΔU 的变化恰为 −(已实现收益)；本期投资贡献 = 已实现 + ΔU = 只剩持有部分的价格变动。买入按市价成交时 U 不变，不产生虚假收益。该恒等式在纯 CNY 下严格成立（测试钉死）；多币种下流量按期末汇率折算，近似误差并入汇兑/残差披露。

## 4. 现金预测

```
C(t)  = Σ现金账户余额(折本位币, 流动性≤T天) + Σ事件(date ≤ t)
R(t)  = 准备金占用（目标预留+应急金；对应支出日自动释放，避免双扣）
B     = 额外最低现金底线
计划外可支配上限 = max(0, min_t [ C(t) − R(t) − B ])     t ∈ [今天, 今天+90天]
```

防重复扣减规则（全部有测试）：
- 期初余额已含预留现金 → R 只在公式里扣一次；
- 支付日 C 下降的同时 R 释放等额；
- 信用卡只按"还款流出"入预测（消费不再二次扣现金）；
- 已实际支付的计划由服务层过滤出事件列表；
- 同日多事件顺序未知 → **先流出后流入**（保守情景）；
- 总现金充足 ≠ 每张卡充足：逐账户独立检查缺口。

## 5. 债务算法

| 方式 | 每期 | 说明 |
|---|---|---|
| 等额本息 | A = P·i(1+i)ⁿ/((1+i)ⁿ−1)；本金 = A − 利息 | i = 名义年利率/12（国内惯例）；末期吸收累计舍入差 |
| 等额本金 | 本金 = P/n；利息 = 剩余×i | |
| 先息后本 | 利息 = P×i；末期还本 | |
| 固定分期(等本等费) | 本金 = P/n；费 = **原始本金**×i | 用 IRR 揭示真实年化（名义 7.2% 实际 ≈13%） |
| 免息 | 本金 = P/n | |

- 利率精确用 `Rational`，每期舍入到分。
- **有效年化** = 月度 IRR（现金流：期初 +P，每期 −(本+息+费)）×12（名义口径年化，XIRR 日期口径见 §6）。
- **提前还款**：按剩余本金与剩余期数重排（保月供缩期 / 保期限降月供），返回利息净节省（已扣手续费）。
- **雪崩 vs 雪球**：逐月模拟，月息 = 剩余×apr/1200；先付各笔最低还款，额外资金按策略注入；还清一笔后其最低还款滚入资金池。

## 6. 投资收益率

- **TWR（时间加权）**：r_k = (V_end − F_k)/V_start − 1，链乘 Π(1+r_k)。排除外部资金进出干扰，衡量投资能力。**组合边界约定：内部买卖不是外部流**。
  估值点取月末（近 13 个 + 今天）；任一在持仓缺价/缺汇率的时点整体作废，不作"缺价计 0"；有效点 <2 时返回 null。年化按估值点跨度实际天数复利（日历日，`calendarDaysBetween`，避免夏令时少 1 小时导致 inDays 少 1 天）。
- **XIRR（资金加权）**：实际/365 折现的 NPV=0，牛顿迭代 + 二分兜底；现金流同号/不收敛返回 null（显式"无法计算"而非编造数字）。
- 已实现损益 = 净回款 − 平均成本×数量（平均成本法）。
- 年度报告口径：总收支/储蓄率/储蓄月数 = 12 个月月报聚合（月报口径见 §3）；最大单笔消费按分类分录金额取全年最大；已实现损益/分红取 12 个月归因行合计（账面口径）。

## 7. 预算口径

- 消费发生即占用（信用卡消费占用、还款不占用；贷款本金不占用，利息按其口径占用）。
- 信封：剩余 = 额度 + 结转 − 已花 − 已计划 − 已预留。
- 结转策略：不结转 / 全额 / 上限；超支月不产生负结转（v1 只展示超支）。

## 8. 汇率

- 有理数精确（如 7.2 = 36/5）；换算 minor_out = minor_in × rate × 10^(d_to−d_from)，halfEven。
- 历史：取 ≤ 时点最近一条；缺失时该资产计 0 并计入"待处理"，**绝不假装有汇率**。

## 9. 风险指标（v0.5）

输入 = TWR 月度子期间收益序列（§6 的估值点切分，外部现金流已剔除；近 36 个月）。
全部为**比率类展示口径**（double 允许；金额链路不经过本节）：

- **年化收益** = Π(1+r_k)^(365/days) − 1（与 TWR 年化同口径）。
- **年化波动率** = 月收益样本标准差（n−1）× √12；常数序列（浮点方差 ≤ 1e-24 级噪声）视为 0 → 波动率/Sharpe 为 null。
- **最大回撤** = TWR 指数（1 起步复利）峰到谷的最大跌幅，记录峰/谷日期；无回撤（单调不跌）为 null。
- **Sharpe** = (年化收益 − 无风险利率) / 年化波动率。无风险利率为设置项 `riskFreeRatePercent`（默认 2.0%）。
- **Sortino** = (年化收益 − 无风险利率) / 年化下行偏差；下行偏差以 MAR = 月度无风险利率 (1+rf)^(1/12)−1，除以 n（总体口径）。
- **最佳/最差月**与**月胜率**（r > 0 占比）按子期间统计。
- 样本规则：子期间 < 2 个不计算；< 6 个月标注"样本不足，仅供参考"。估值点缺失纪律同 §6（缺价该点作废）。

## 10. 资产配置与再平衡（v0.5）

- **九类配置桶**（`AllocationClass`，把账户子类型收敛；负债不参与）：
  股票 / 基金（股债混合单列）/ 债券 / 现金及等价物（含货基、券商现金）/ 固收理财（定期、银行理财）/ 另类资产（贵金属、加密、公司股权）/ 固定资产（房产、车辆）/ 长期权益（养老金、公积金、保险现金价值）/ 其他（押金、应收、其他资产）。
- 配置值 = 净资产构成资产端按桶聚合（本位币）；估值缺失账户按 0 计并披露数量。
- **目标配置**：设置键 `allocationTargets`（JSON，类名 → 整数百分比），合计 ≤ 100%，未设目标的类不参与再平衡。
- **5/25 带宽再平衡**（Vanguard 阈值法）：阈值 = max(5 个百分点, 目标×25%)；
  |当前占比 − 目标| > 阈值 → 提示交易**回带边**（目标 ± 阈值，而非回到目标，降低换手）；建议金额 = |当前 − 带边| × 全部资产总值（Rational 精确计算，halfEven 取整）。

## 11. FIFO 批次成本（v0.5，分析视角）

- **账面口径不变**：卖出仍按平均成本法过账（§2 事件表、TxBuilders.sell）。
- 批次引擎（`LotEngine`）对同一份 buy/sell 交易做**先买先卖逐批配对**的分析视图：
  买入（含费用，费用资本化）开批次，单位成本 = 总付/数量（有理数精确）；
  卖出（净回款）按 FIFO 依次消耗批次，产出逐笔配对（数量/回款/成本/盈亏/持有天数，日历日）。
- **舍入尾差两个吸收点**：卖量用尽 → Σ配对回款 = 净回款；批次耗尽 → Σ配对成本 = 批次成本。金额全程 BigInt。
- 卖出量超过已知批次（历史早于首笔买入）：缺口数量以零成本配对并显式披露（`shortfallQuantity`），绝不静默。
- 输出：剩余批次明细（买入日/数量/单位成本/剩余成本）、FIFO 已实现累计与按年汇总；与账面平均成本口径并行展示，标注差异来源。

## 12. 情景模拟（v0.7，现金流压力测试）

情景 = 对 §4 现金预测**事件流**的确定性变换，不写账本、不改期初余额。

- **组件**（可组合，按列表顺序串联，前一个的输出是后一个的输入）：
  - 收入冲击（`IncomeShock`）：窗口内 `incomeExpected` 事件 ×(1−drop)，drop=1 即失业中断；
  - 工资延发（`IncomeDelay`）：窗口内收入事件日期 +delayDays，推出预测期外由投影器自动丢弃（现金视角：到账才算数）；
  - 支出激增（`ExpenseSurge`）：仅作用于 `planned`（固定/预定支出）；`debtRepay` 为合同义务不放大，`budgetBaseline` 不重复放大；
  - 一次性事件（`OneOffEvent`）与额外月度流出（`ExtraMonthlyOutflow`）：追加 `other` 类事件（月末锚点 clamp 与计划同规则）。
- **窗口** = [from + startAfterDays, addMonthsClamped(start, months)]，含两端。
- **对比**（`ScenarioComparison`）：基线与情景共用同一份预测输入（`ProjectionService.buildInput`），仅事件流不同，同引擎重放（同日支出先于收入的保守规则不变）。指标：最低现金变化、逐日差最差值、现金耗尽日与剩余天数（总现金 < 0，未扣准备金）、新增缺口（日期+账户+原因三元组不在基线中的）、缺口总额变化、`survives`（无新增缺口且未耗尽）。
- 金额变换经 Rational 乘法后 halfEven 取整；防御性不变式：收入冲击不产生负收入、支出激增不把流出变成流入。

## 13. FIRE 财务独立规划（v0.7）

- **FI 门槛**（今天的钱）= 目标年支出 ÷ 提取率（默认 4% 法则；有理数精确，halfEven 取整）。
- **可投资净资产**（服务层预填，UI 可改）= 净资产 − 固定资产桶 − 长期权益桶，**负债全额抵减**（保守口径：视负债优先侵蚀可投资资产），下限 0。
- **储蓄/支出预填**：近 12 个完整月（不含本月）实绩；历史不足 12 个月在 UI 披露。
- **累积期**（`FirePlanner.plan`）：名义月利率 = 名义年利率/12（与 §5 债务同口径），目标门槛按月通胀复利（月率 = 年率/12），**全程有理数精确复利**，达标判定 p_t ≥ target_t，逐月推进上限 maxYears（默认 50 年）；零储蓄且名义收益 ≤ 通胀判不可达。曲线按年采样 + 达标月。
- **反解**（`requiredAnnualSavingsMinor`）：想在 N 年达标的闭式解 s = (T_n − p0·gⁿ)(g−1)/(gⁿ−1)（g=1 线性退化），负值钳 0；halfEven 取整到年储蓄。
- **敏感性**：名义收益 −1/0/+1 个百分点 × 支出 ×0.9/×1.0/×1.1 的 3×3 达标年数网格。
- **蒙特卡洛提取期**（`FireMonteCarlo.survival`，Trinity/FIRECalc 风格）：全程在**年支出倍数**空间运行（期初 k 倍 = 提取率倒数），每年先按随机实际收益增长再提取 1 倍（实际口径：支出已随通胀调整），30 年不耗尽为成功；收益 ~ N(实际均值, 实际波动)，实际均值 = (1+名义)/(1+通胀) − 1（Fisher）；正态抽样 Box-Muller，`Random(seed)` 固定种子 → 同参数可复现。输出：成功率与期末余额的年支出倍数分位（P10/P50/P90，耗尽计 0）。**没有任何金额经过 double**。
- 边界：提取率 ≤ 0 或无支出目标 → 无门槛（曲线仍可用、达标不可达）；years ≤ 0 反解抛 ArgumentError。
